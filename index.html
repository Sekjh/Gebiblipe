Fonctionnalités

  • Recherche par ISBN ou ISSN français — détection automatique du type d'identifiant, validation checksum, conversion ISBN-13/10 ; l'ISSN interroge uniquement BnF et SUDOC (OpenLibrary et Google Books n'indexent pas l'ISSN) ; l'identifiant doit être renseigné pour permettre l'envoi vers Notion dans ce mode
  • Ajout manuel sans ISBN via le bouton « Nouveau sans ISBN » — formulaire vide éditable, Titre obligatoire avant envoi ; case à cocher technique « Saisie manuelle » cochée automatiquement dans Notion dès qu'aucune source bibliographique n'a contribué (ajout manuel ou recherche ISBN infructueuse)
  • Import en masse d'ISBN via le bouton « Import en masse (ISBN) » — champ libre où coller une liste d'ISBN (un par ligne) ; chaque ISBN est vérifié dans Notion, ses champs bibliographiques vides sont complétés via les 4 sources, ses identifiants techniques et sa version GEBIBLIPE sont rafraîchis, et un tableau récapitulatif (statut, champs modifiés) permet de valider ou d'exclure chaque entrée avant l'envoi groupé vers Notion ; « Saisie manuelle » est cochée dès qu'aucune source n'a retrouvé le livre, même pour une fiche déjà présente dans Notion
  • Sources bibliographiques multi-moteurs : BnF (recommandée), OpenLibrary, Google Books, SUDOC (catalogue collectif universitaire)
  • Enrichissement automatique avec fallback — une source suivante est consultée tant qu'un champ bibliographique sélectionné manque
  • Champs bibliographiques configurables (Éditeur, Date édition, Langue, Pages, Couverture, Format/reliure, Collection, Genre, Résumé) via un panneau dédié, regroupés par cercle d'intérêt selon leur taux de complétion (Socle, Très utile, Valeur variable) — Titre et Auteur affichés en tête du Cercle 1 comme toujours actifs, ISBN toujours présent ; le regroupement par cercle est aussi visible directement dans la fiche de saisie, avec un séparateur par cercle
  • Genre extrait automatiquement via Google Books ; Résumé extrait automatiquement via Google Books ou OpenLibrary (repli sur la notice BnF/SUDOC si elle porte un résumé, rarement le cas pour un livre de commerce courant), activé par défaut dans les champs bibliographiques ; Langue extraite depuis BnF, OpenLibrary et Google Books avec normalisation ISO 639-1 (Genre en propriété Notion multi_select)
  • Identifiants pivots (ARK BnF, OLID, Google Volume ID, OCLC, PPN SUDOC) collectés en best-effort, affichés en lecture seule dans le popover de sources et envoyés à Notion dès qu'ils sont disponibles
  • Gestion de couverture via OpenLibrary Covers — badge de source, validation fiable (Content-Type) laissant le champ entièrement vierge en l'absence de couverture réelle ; la cover envoyée sur la page Notion utilise l'image haute résolution (OLID, repli ISBN)
  • 12 thèmes (dont « Presse & périodiques » pour les revues et journaux catalogués via ISSN) et leurs sous-thèmes, avec suggestion automatique via IA (Claude Haiku)
  • Génération de fiche de lecture via IA (Claude Sonnet)
  • Intégration Notion : pré-vérification ISBN, création et mise à jour de page
  • Synchronisation automatique du schéma Notion (propriétés manquantes créées selon les champs bibliographiques actifs)
  • Version technique de l'application enregistrée automatiquement dans chaque fiche Notion (colonne « Version GEBIBLIPE »), pour tracer la version ayant traité l'entrée
  • Badges de source par champ (ISBN, Notion, IA) + journal de recherche en popover — colorés selon la source bibliographique réelle (BnF, OpenLibrary, Google Books, SUDOC)
  • Détection automatique des éditions spéciales et collections
  • Support iOS Shortcuts via paramètre URL ?isbn=XXXXX
  • Notifications ponctuelles (pop-up en haut à droite, fermeture par croix ou touche Échap ; seules les informations s'effacent automatiquement, succès/avertissements/erreurs restent affichés jusqu'à fermeture manuelle, 3 au maximum empilés) : envoi/sauvegarde Notion et configuration, chargement d'une fiche depuis Notion, résultat de recherche ISBN/ISSN, détection de doublon, complétion de champs depuis les sources, et échecs de suggestion de thème / génération de fiche par l'IA
  • Interface dark mode, responsive mobile
  • Avertissement discret si la configuration Notion (token, database ID, proxy) est incomplète

Guide d'initialisation

  1. Base Notion
    Créer une page de base de données vierge dans Notion (sans modèle). Copier l'identifiant de 32 caractères depuis l'URL de la page. L'application crée automatiquement toutes les propriétés nécessaires lors du premier enregistrement.
  2. Intégration Notion
    Aller sur notion.so/my-integrations → "New integration". Nommer l'intégration (ex. "GEBIBLIPE"), sélectionner l'espace de travail, copier le token (ntn_… ou secret_…). Dans Notion, ouvrir la base → "…" → "Ajouter des connexions" → sélectionner l'intégration.
  3. Proxy Cloudflare (recommandé)
    Les navigateurs bloquent les appels directs à l'API Notion (CORS). Créer un compte Cloudflare gratuit → Workers → nouveau worker avec un script de proxy CORS vers api.notion.com. Copier l'URL du worker (ex. https://xxx.workers.dev).
  4. Clé API Anthropic (optionnelle)
    Pour les fonctionnalités IA (suggestion de thème, génération de fiche). Créer un compte sur console.anthropic.com → API Keys. Le token commence par sk-ant-.
  5. Configuration dans l'appli
    Cliquer sur ⚙ configuration en bas de page. Renseigner les champs (proxy, token, database ID, clé Anthropic). Cliquer sur "Vérifier et enregistrer" — l'application synchronise automatiquement le schéma de la base Notion.
